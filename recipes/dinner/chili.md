# Chili

## Ingredients

| Qty | Unit | Ingredient | Prep |
|---|---|---|---|
| 2 | lb | ground beef |  |
| to taste | tsp | kosher salt |  |
| to taste | tsp | black pepper |  |
| 2 | each | carrot | diced |
| 1/4 | bunch | celery | 2 stalks, diced |
| 1 | each | yellow onion | diced |
| 1 | each | jalapeño | diced |
| 4 | clove | garlic | minced |
| to taste | tsp | chipotle chili powder |  |
| to taste | tsp | ground cumin |  |
| 3 | cup | chicken broth |  |
| 1 | can | canned tomato sauce (15 oz) |  |
| 1 | each | bay leaf |  |
| to taste | tsp | dried oregano |  |
| 1 | can | canned kidney beans (15 oz) |  |
| 1 | can | canned black beans (15 oz) |  |

## Instructions

1. Season the ground beef with salt and pepper and brown it until fond forms on the bottom of the pot.
2. Add the carrot, celery, onion, and jalapeño (not the garlic). Deglaze, then cook until fond forms again.
3. Add the chipotle chili powder, cumin, and garlic and cook off briefly.
4. Deglaze with the chicken stock and tomato sauce.
5. Add the bay leaf, oregano, and beans. Bring to a boil, then drop to a simmer and cook for 1 to 2 hours.
