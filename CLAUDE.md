# Recipes

A personal recipe collection with an ingredient index, meal plans, and
shopping lists. Everything is plain Markdown.

## Layout

```
ingredients.md                 Ingredient index: the single source of names, units, aisles
preferences.md                 Household defaults for meal planning (created by /meal-plan)
recipes/<category>/<slug>.md   One recipe per file; category is breakfast, lunch, dinner, or side
recipes/<category>/images/     Recipe photos, named <slug>.<ext>
meal-plans/<start-date>.md     Meal plans (status: draft or accepted)
shopping-lists/<start-date>.md Shopping lists generated from accepted plans
scripts/recipes.py             Helper: validate, list, lookup, shopping-list
```

## Rules

- Every ingredient in a recipe must exist in `ingredients.md`, using the
  index's exact name and unit. That's what makes shopping lists combine.
  Add new ingredients to the index rather than using one-off names.
- Recipe ingredients live in a `| Qty | Unit | Ingredient | Prep |` table
  under `## Ingredients`. No `|` characters inside cells.
- Recipe frontmatter is flat `key: value` lines (name, category, servings
  required).
- Shopping lists are generated by the script from a plan file, not written by hand.
- After changing a recipe or the index, run `python scripts/recipes.py validate`.

## Skills

- `/create-recipe`: add a recipe and normalize its ingredients into the index.
- `/meal-plan <days>`: draft a plan for review, then produce the shopping list.

## Script

```bash
python scripts/recipes.py validate                 # check index + all recipes
python scripts/recipes.py list --ingredients       # all recipes with ingredients
python scripts/recipes.py lookup "green onion"     # search the index
python scripts/recipes.py shopping-list meal-plans/2026-11-09.md -o shopping-lists/2026-11-09.md
```
